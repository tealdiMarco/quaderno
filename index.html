Sincronizzazione con GitHub

Le note restano file .md in un tuo repository. Il token resta solo su questo dispositivo: va inserito una volta su ogni telefono o computer.

Come creo il token
  1. Su GitHub: Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. In "Repository access" scegli "Only select repositories" e seleziona solo il repo degli appunti.
  3. In "Permissions" imposta Contents su "Read and write".
  4. Copia il token e incollalo qui.

Importa note

Vengono importati file .md, immagini e PDF (fino a 25 MB ciascuno) e poi inviati al repository alla prossima sincronizzazione.
